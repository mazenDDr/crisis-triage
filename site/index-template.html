Crisis triage · a measured experiment

When the messages outnumber the people.

After a disaster, messages arrive faster than anyone can read them. A small model can read each one in a fraction of a second. The question is not whether it can guess, but whether it knows when it's guessing. If it does, its sure answers can go straight through, and people read the rest.

1 · The flood

Real messages from real disasters, in many languages.

Everything here was measured on four public collections of crisis messages. The test messages come from disasters that happened after the ones used for tuning, so no system saw them before.

A random sample of test tweets. User names, links and phone numbers are hidden.

2 · One message, one pass

Laya reads a message and scores every answer at once.

It doesn't write a reply; it scores each possible answer in a single pass. The top score is its guess, and how high it is says how sure it is. Answers above the safety line go straight through.

These are the first short test tweets in each language from a random sample, not picked for looking good, and some are answered wrong. Recorded answers of the fine-tuned Laya.

3 · The twist

Sure is not the same as right.

Big chat models say they are almost certain about almost everything. Trust that, and wrong answers go out with nobody checking. Each square is 1 of 100 real test tweets.

5 · Languages

It didn't read Haitian Creole well, at first.

Text messages sent to Haiti's 4636 help line after the 2010 earthquake are mostly in Haitian Creole. Out of the box, Laya misread many of them. Two fixes work: translate each message to English first with an open translation model, or teach Laya with past messages.

Score: how well each version ranks messages that ask for rescue, medical help, water or food, and shelter (mean AUC; 1.0 is perfect, 0.5 is guessing). The SMS text itself is not shown: that dataset does not state a licence.
